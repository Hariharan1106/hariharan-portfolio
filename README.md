# Anantha Hariharan V — Portfolio

A personal portfolio website for a Frontend Developer featuring a dark/light theme, smooth animations, and responsive design.

## Tech Stack

- **HTML5** — Semantic markup
- **CSS3** — Custom styling with CSS variables, animations, responsive design
- **JavaScript** — Vanilla JS for interactivity

## Features

- Dark/Light theme toggle with localStorage persistence
- Custom cursor effect (desktop only)
- Scroll reveal animations with Intersection Observer
- Smooth scrolling navigation
- Active nav link highlighting
- Mobile hamburger menu
- Contact form with simulated submission
- Responsive design (mobile, tablet, desktop)

## Sections

1. **Home** — Hero with name, title, stats, decorative code block
2. **About** — Bio, location, availability
3. **Skills** — Tech stack with progress bars (HTML5, CSS3, JavaScript, React.js, Bootstrap, MySQL, Git)
4. **Projects** — Todo App, Portfolio, Weather App
5. **Contact** — Email, GitHub, LinkedIn, contact form

## Getting Started

Open `index.html` in a browser. No build step required.

## Customization

Edit `index.html` to update:
- Name, bio, skills, projects
- Contact info (email, GitHub, LinkedIn URLs)

## Browser Support

Chrome, Firefox, Safari, Edge (modern browsers)
